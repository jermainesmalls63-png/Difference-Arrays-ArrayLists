# Difference-Arrays-ArrayLists
Java program comparing arrays and ArrayLists
Arrays and ArrayLists allow the storage of many values in Java. Although they are closely related, they also differ, and it is important to know their applications.
Arrays allow a developer to create a data structure that can hold many values of the same type. They can be regarded as variables that can hold many values. Arrays have a fixed length. Once an array is created, its length can’t be changed. So if I am creating an array of five elements, I cannot add a sixth element to that array. This limits the use of arrays. Arrays are efficient if the number of elements is small and if they are accessed by their index.
Because of the limitations of arrays, the ArrayList class was created to provide an array-like data structure while removing their limitations. This class makes it very easy to manipulate a data structure.
Arrays can't grow or shrink when elements are added or removed. This can make their management difficult. A good thing about ArrayLists is that they can grow or shrink easily, but they do have memory overhead. Also, ArrayLists use wrapper classes for primitives.
For my project called "Difference-Arrays-ArrayLists", I wrote a Java program to illustrate both structures for storing and displaying numbers. I also illustrated how an ArrayList can keep growing and an array maintains a constant length. This project demonstrated the importance of selecting the right data structure for a Java application.
I think arrays should be used when dealing with a fixed and small number of elements. For a large or variable number of elements, I would use ArrayLists. Knowledge and application of these concepts will be useful to me for developing organized and more functional Java programs.
